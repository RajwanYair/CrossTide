## Overview

CrossTide ships a standalone ES module bundle, `widget.mjs`, that auto-registers
three custom elements:

- `<crosstide-chart>` (OHLCV candles)
- `<crosstide-quote>` (quote tape/badge)
- `<crosstide-consensus>` (consensus direction and score)

These are the smallest way to reuse CrossTide surfaces outside the full
application shell. All widgets use closed Shadow DOM so host-page CSS cannot
leak into them.

## Quick Start

```html
<script
  type="module"
  src="https://rajwanyair.github.io/CrossTide/widget.mjs"
></script>

<crosstide-chart
  ticker="AAPL"
  interval="1d"
  range="3mo"
  theme="auto"
  height="320"
></crosstide-chart>

<crosstide-quote ticker="AAPL"></crosstide-quote>

<crosstide-consensus ticker="AAPL"></crosstide-consensus>
```

The element fetches data from `https://worker.crosstide.pages.dev/api/chart` by
default. If you self-host the Worker, set `api-base` to your own origin.

## Attributes

### `crosstide-chart`

| Attribute | Default | Purpose |
| --- | --- | --- |
| `ticker` | `AAPL` | Symbol to chart |
| `interval` | `1d` | Candle interval (`1d`, `1w`, `1mo`) |
| `range` | `3mo` | History window (`1mo`, `3mo`, `6mo`, `1y`, `5y`) |
| `theme` | `auto` | `dark`, `light`, or follow `prefers-color-scheme` |
| `height` | `300` | Widget height in pixels |
| `show-volume` | `true` | Render the volume strip under candles |
| `api-base` | `https://worker.crosstide.pages.dev` | Override the Worker origin |

### `crosstide-quote`

| Attribute | Default | Purpose |
| --- | --- | --- |
| `ticker` | `AAPL` | Symbol to quote |
| `theme` | `auto` | `dark`, `light`, or follow `prefers-color-scheme` |
| `show-change` | `true` | Toggle day change + percent display |
| `api-base` | `https://worker.crosstide.pages.dev` | Override the Worker origin |

### `crosstide-consensus`

| Attribute | Default | Purpose |
| --- | --- | --- |
| `ticker` | `AAPL` | Symbol to evaluate |
| `theme` | `auto` | `dark`, `light`, or follow `prefers-color-scheme` |
| `api-base` | `https://worker.crosstide.pages.dev` | Override the Worker origin |

## Self-hosted Worker

```html
<crosstide-chart
  ticker="MSFT"
  range="1y"
  api-base="https://quotes.example.com"
></crosstide-chart>

<crosstide-quote
  ticker="MSFT"
  api-base="https://quotes.example.com"
></crosstide-quote>

<crosstide-consensus
  ticker="MSFT"
  api-base="https://quotes.example.com"
></crosstide-consensus>
```

The widget trims trailing slashes from `api-base`, so both
`https://quotes.example.com` and `https://quotes.example.com/` are valid.

## Accessibility & Behavior

- The widget renders into a **closed Shadow DOM** for style isolation.
- The chart canvas exposes `role="img"` and an `aria-label` with the ticker symbol.
- Network failures render an inline alert state instead of failing silently.
- Resizing the host container triggers a redraw through `ResizeObserver`.

## Current Scope

The E21 baseline now includes chart, quote, and consensus widgets plus a
host-page smoke test that runs the widgets outside the app shell. Remaining
platform follow-ups are framework adapters and plugin surfaces in Phase T.
