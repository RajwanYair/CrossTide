## 🔭 Overview

The **Provider Health** card displays runtime status for the browser provider registry,
including availability, recent failures, and circuit-breaker state. The Worker health
endpoint separately reports which server-side providers are configured.

## Monitored Providers

### Browser Registry

| Provider      | Role                                  |
| ------------- | ------------------------------------- |
| Yahoo Finance | Primary browser quote/history/search  |
| Stooq         | No-key end-of-day history fallback    |
| Alpaca        | Worker-proxied US equity fallback     |
| Finnhub       | Optional when configured in the app   |
| Tiingo        | Optional when configured in the app   |

### Worker Availability

`GET /api/health` reports configuration availability for Yahoo Finance, Finnhub,
Massive (including the legacy `POLYGON_KEY` binding), Alpha Vantage, Frankfurter,
CoinGecko, Stooq, FRED, and other server-side services. Massive and Alpha Vantage
keys remain on the Worker and are never exposed to browser code.

## Status Indicators

| Status   | Description                                    |
| -------- | ---------------------------------------------- |
| Healthy  | Provider is available and its breaker is closed |
| Degraded | Recent provider errors have been recorded       |
| Down     | Provider is unavailable or its breaker is open   |

## Circuit Breaker

Each provider has an independent circuit breaker:

1. **Closed** (normal) → requests pass through
2. **Open** (tripped) → requests short-circuit to fallback provider
3. **Half-open** (testing) → single test request to check recovery

<Aside type="note">
  The circuit breaker automatically recovers. No manual intervention needed.
  When a provider recovers, traffic shifts back within 30 seconds.
</Aside>

## Toast Notifications

When a provider's status changes, a toast notification appears with:
- Provider name and new status
- Suggested action (if any)
- Dismiss button (keyboard accessible)

## Accessing

Navigate to `/provider-health` from the route selector or sidebar.
